# 串口代理监听与 Modbus RTU 解析工具

Windows 桌面串口工具，支持直接收发和双串口透明代理监听。它会将一段串口静默间隔前收到的数据视为一帧，并自动按照 **Modbus RTU 主机请求报文**解析。

## 直接使用

双击 `release/串口Modbus解析工具.exe` 即可运行。该文件已经包含运行环境，目标电脑不需要安装 Python。后续版本统一覆盖这个文件，不再保留多个版本化 EXE。

## 代理监听接线和设置

Windows 通常不允许两个程序同时打开同一个 COM 口，因此监听其他串口软件时需要先创建一对虚拟串口。假设虚拟串口对为 `COM10 ↔ COM11`，真实 USB/RS485 串口为 `COM3`：

1. 原串口软件连接 `COM10`，串口参数保持不变。
2. 本工具选择“代理监听”模式。
3. “代理端口”选择 `COM11`，“设备端口”选择 `COM3`。
4. 打开串口后，工具透明转发 `COM10/COM11 ↔ COM3` 的数据。
5. “主机→设备”报文自动按 Modbus 主机请求解析，“设备→主机”报文以绿色显示并原样转发。

工具提供“自动创建虚拟串口对”按钮：如果已经安装 com0com，它会自动寻找空闲的连续 COM 号、请求管理员权限创建，并将工具端自动填入代理端口。如果未检测到 com0com，会询问是否打开其官方项目下载页。

虚拟串口属于 Windows 内核设备，本程序不会静默下载或安装驱动。首次使用仍需由用户确认安装受信任的 com0com（或同类驱动）。不要让原串口软件和本工具选择虚拟串口对的同一端。

## 功能

- 串口参数：端口、波特率、数据位、停止位、奇偶校验
- 双串口透明代理，监听其他串口软件与真实设备之间的双向通信
- 自动检测 com0com、选择空闲端口号并通过 UAC 创建虚拟串口对
- HEX 或 UTF-8 文本发送，可自动追加 Modbus CRC
- 接收报文以 HEX 显示，并解析设备地址、读/写操作、功能码、寄存器/线圈起始地址、数量
- 接收线程先等待 RTU 帧间隔，再对驱动缓冲区执行一次整帧读取，串口监听器不会显示为首字节和后续字节两次读取
- CRC-16/Modbus 校验，同时显示报文携带值与计算值
- 校验设备地址、寄存器/线圈数量、批量写字节数和值域，结构异常报文标红
- 支持功能码 `01`、`02`、`03`、`04`、`05`、`06`、`08`、`0F`、`10`、`16`、`17`
- 无串口设备时也可用“手动解析 HEX”验证报文

## 运行

```powershell
cd tools\serial_assistant
python -m pip install -r requirements.txt
python app.py
```

重新生成 EXE：

```powershell
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --clean --onefile --windowed --name "串口Modbus解析工具" --distpath release --workpath build app.py
```

运行测试：

```powershell
python -m unittest -v
```

示例：`01 03 00 00 00 02 C4 0B` 将解析为设备地址 1、读保持寄存器、起始地址 0、数量 2、CRC 正确。
